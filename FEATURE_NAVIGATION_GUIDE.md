🗺️ FEATURE NAVIGATION GUIDE
============================

This guide shows where to find and use each new feature.


1️⃣ LOYALTY POINTS PROGRAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Location: Navbar → 💎 Loyalty

What you'll see:
├─ Your current points balance (large display)
├─ How to earn points breakdown
│  ├─ 1 point per ₹ spent (on purchases)
│  ├─ +5 points (add to wishlist)
│  ├─ +10 points (write review)
│  └─ +500 points (per referral)
├─ Your referral code display
├─ Friends referred count
├─ Bonus points earned from referrals
├─ Rewards tiers table
│  ├─ Bronze Member (0-500 pts): 5% bonus
│  ├─ Silver Member (500-2000 pts): 10% bonus + free delivery
│  └─ Gold Member (2000+ pts): 20% bonus + VIP support
└─ Copy referral code button

How to earn:
1. Make a purchase → 1 point per rupee
2. Save items → 5 points per wishlist
3. Write review → 10 points per review
4. Refer friends → 500 points per referral
5. Get referred → 250 points (as new member)


2️⃣ REFERRAL & EARN PROGRAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Location: Navbar → 👥 Refer & Earn

What you'll see:
├─ "How Referral Works" visual (4 steps)
├─ Your unique referral code (center, highlighted)
│  └─ Copy button for easy sharing
├─ Referral stats
│  ├─ Friends Referred (count)
│  └─ Bonus Points Earned (₹ value)
├─ Share options
│  ├─ 💬 Share on WhatsApp
│  ├─ 𝕏 Share on Twitter
│  └─ 📋 Copy & Share
├─ Rewards breakdown table
├─ FAQ accordion
│  ├─ "How long does it take?"
│  ├─ "Is there a limit?"
│  └─ "Can I use points?"
└─ Share all your stats below

How to use:
1. Copy your referral code (REF-YOURNAME)
2. Share via WhatsApp, Twitter, or copy
3. Friend registers with your code
4. Friend gets 250 bonus points
5. You get 500 bonus points
6. Both can enjoy loyalty benefits


3️⃣ WISHLIST & FAVORITES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Location 1: Navbar → ❤️ Wishlist
Location 2: Any item detail page → "❤️ Add to Wishlist" button

On Wishlist Page:
├─ Header: "❤️ My Wishlist"
├─ Subtext: "Items you've saved for later"
├─ Item cards showing:
│  ├─ Item emoji/image
│  ├─ Item name & category
│  ├─ Price (₹)
│  ├─ "View Details" button
│  └─ "Rent Now" button
└─ Empty state if no wishlist items

How to use:
1. Browse items in Menu
2. Click on any item
3. At bottom, click "❤️ Add to Wishlist"
4. Item saved, you get +5 loyalty points
5. View all wishlists at 💎 Wishlist link
6. Click "Rent Now" for quick checkout


4️⃣ RATINGS & REVIEWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Location: Item detail page (scroll down)

What you'll see:

EXISTING REVIEWS SECTION:
├─ "Customer Reviews & Ratings" heading
├─ Average rating (⭐ X.X / 5)
├─ Total review count
├─ Individual reviews showing:
│  ├─ Username & date
│  ├─ Star rating (filled/empty)
│  └─ Review comment text
└─ "Loading..." if no reviews yet

REVIEW SUBMISSION FORM:
├─ "Share Your Experience" heading
├─ Rating selector (5 clickable stars)
├─ Review text area (required)
├─ "Submit Review" button
└─ Confirmation: You get +10 loyalty points

How to use:
1. Go to any item detail page
2. Scroll down to "Customer Reviews"
3. Read existing reviews
4. Click stars to rate (1-5)
5. Write your review/comment
6. Click "Submit Review"
7. Get +10 loyalty points
8. See your review appear below

New Registration Form Fields:
├─ Full Name * (required)
├─ Username * (required)
├─ Email * (required)
├─ Phone (optional)
├─ City (optional)
├─ Password * (required)
└─ 🆕 Referral Code (optional)
   └─ Placeholder: "REF-YOURFRIEND"
   └─ Bonus: "Get 250 bonus points!"

1. Go to /auth page
2. Click "Register" tab
3. Fill all fields
4. Enter referral code if you have one
5. Click "Create Account"
6. If code is valid:
   ├─ You get +250 bonus points
   ├─ Referrer gets +500 bonus points
   └─ Referral tracked
7. If no code: You get +100 new member bonus

Step 1: Registration
  → Go to /auth
  → Click Register tab
  → (Optional) Enter referral code
  → Get +100 or +250 bonus points

Step 2: Browse
  → Click Menu in navbar
  → Browse items
  → Click any item to see details

Step 3: Wishlist (Optional)
  → On item page, click ❤️ Add to Wishlist
  → Get +5 loyalty points
  → Access wishlist via navbar

Step 4: Reviews (Optional)
  → On item page, scroll down
  → Read existing reviews
  → Submit your review
  → Get +10 loyalty points

Step 5: Purchase
  → Add items to cart
  → Go to checkout
  → (Optional) Apply promo code
  → Complete payment
  → Get 1 point per ₹ spent

Step 6: Share (Viral!)
  → Go to 💎 Loyalty → See referral code
  → OR go to 👥 Refer & Earn
  → Copy code & share on WhatsApp/Twitter
  → Friends get +250 points
  → You get +500 points per referral

Step 7: Redeem
  → Check loyalty level
  → Enjoy tier benefits
  → Use points at future checkout
